# Accordion

Accordion displays collapsible content sections for organizing information.

## Responding to Changes

`onChange` receives the expanded item index in single mode, or all expanded
indexes when `allowMultiple` is enabled.

```tsx
<Accordion onChange={(index) => console.log(index)}>
  <AccordionItem title="Account">Account settings</AccordionItem>
  <AccordionItem title="Security">Security settings</AccordionItem>
</Accordion>
```

## Controlled State

Use `index` with `onChange` when the expanded state belongs to your
application. A controlled Accordion reports the requested change but does not
update until you pass the new index back.

```tsx
function ControlledAccordion() {
  const [expandedIndex, setExpandedIndex] = useState<number | null>(0);

  return (
    <Accordion index={expandedIndex} onChange={setExpandedIndex}>
      <AccordionItem title="Account">Account settings</AccordionItem>
      <AccordionItem title="Security">Security settings</AccordionItem>
    </Accordion>
  );
}
```

For multiple expanded items, pass an array together with `allowMultiple`:

```tsx
const [expandedIndexes, setExpandedIndexes] = useState<number[]>([0]);

<Accordion
  allowMultiple
  index={expandedIndexes}
  onChange={setExpandedIndexes}
>
  {/* AccordionItem children */}
</Accordion>
```

## Props Reference

### Accordion

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| index | `number` \| `number[]` \| `null` | - | Expanded index(es) for controlled usage |
| defaultIndex | `number` \| `number[]` | - | Default expanded index(es) |
| allowMultiple | `boolean` | `false` | Allow multiple items expanded |
| onChange | `(index: number \| number[] \| null) => void` | - | Called with the requested expanded state after an item is toggled |
| className | `string` | - | Additional CSS class |
| children | `ReactNode` | - | AccordionItem children |

### AccordionItem

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| index | `number` | Item position | Optional item index override |
| title | `ReactNode` | - | Item header (required) |
| disabled | `boolean` | `false` | Whether item is disabled |
| className | `string` | - | Additional CSS class |
| children | `ReactNode` | - | Item content |

## Accessibility

- Uses `aria-expanded` on trigger buttons
- Associates each trigger and panel with `aria-controls` and `aria-labelledby`
- Removes collapsed panel content from interaction while preserving its transition
- Uses `aria-disabled` for disabled items
- Keyboard accessible via Tab and Enter/Space
